# JUNGLE OF TENSES — The Lost Expedition

A complete, original, two-player English classroom game inspired by classic jungle adventure board games.

## How to open (Windows / Mac / Linux)

1. Extract the ZIP file.
2. Open `index.html` in **Chrome, Edge, Firefox, or Safari**.
3. Type both players' names and select Short Quest (18 spaces) or Full Adventure (36 spaces).
4. Click **ENTER THE JUNGLE**.

**No installation, server, database, npm, or login needed.** The game works from a local folder. Google Fonts are optional; local fallback fonts work without an internet connection.

## How to play

- Two players share one device and take turns.
- Roll the six-sided die.
- Choose **WILL** or **BE GOING TO** for the grammar challenge.
- If correct, move the rolled number of spaces. If wrong, stay put and read the explanation.
- Golden spaces give extra moves; red spaces take you back.
- The first player to reach space **18** (Short Quest) or **36** (Full Adventure) wins.
- Use the Field Guide to study the rules.

Keyboard shortcuts: **Space** = roll, **A** = WILL, **B** = BE GOING TO, **Enter** = continue.

## Grammar overview

**WILL**: decisions made right now, offers, promises, predictions based on personal opinion.
- `I will help you.`
- `I think we will win.`

**BE GOING TO**: earlier plans, intentions and predictions based on visible evidence.
- `I'm going to study tonight.`
- `Look at those clouds! It's going to rain.`

## Project structure

- `index.html` — entire game interface and accessible dialogs
- `css/style.css` — responsive jungle-inspired visual design
- `js/game.js` — board, questions, dice, animations, points and victory logic

There are **44 question cards** (22 for WILL and 22 for BE GOING TO), each with context-specific explanations.

All graphics and names are original, without movie assets or copyrighted branding.
